Clases Disponibles

Fracciones

  • one-whole → 100%
  • one-half → 50%
  • one-third → 33.33%
  • two-thirds → 66.66%
  • one-quarter → 25%
  • three-quarters → 75%

Modificadores Responsive

  • palm--* → Móvil (< 768px)
  • lap--* → Tablet (768px - 1023px)
  • desk--* → Desktop (> 1024px)
